This is a self improvement tool. There are definitely ways to cheat it and get unlimited XP fast. If you're here for that then you are in the wrong place. 
I made this tool for myself because I have an addiction to doom scrolling reels, shorts, and linkedin. It is such a waste of time. I want to go outside and improve myself and spend time with my friends, not turn my brain into mush and waste away. I got this idea from Focus Friend, which is available on mobile, where it gamifies focusing and reducing app usage. Once I had my mobile usage under control, I resorted to scrolling on my laptop. I could not find a solution like Focus Friend for web, so I made one myself. The gamification is XP points which is pretty underwhelming compared to Focus Friend, but I hope to work on that in the future with my new found free time.

# To start using FocusUp:
1. Clone the repo
2. In your browser (I use Brave):
3. Press the Extension Button (shaped like a puzzle piece)
4. Manage extensions 
5. Enable Developer Mode in the top right
6. Press Load Unpacked
7. Select the Focus Up repository you just cloned
8. Enable it
9. Open up the extension and start your first lock in session

# Blocking more website:
1. Once the repo is cloned:
2. Go into /config
3. Add/Remove websites in blocked_urls.json
